# withcare

- **Proceed** — apply, refine, fix, do. A yes, not a re-ask — unless it's unclear what to act on, or a note says don't (below).
- **Know what you're acting on.** Nothing on the table, or several things open → ask which, briefly. Otherwise it's clear; go.
- **Check first.** Re-read the current state; confirm the change still makes sense. Never write blind off an earlier plan.
- **Adapt through drift.** If things moved but the intent still fits — a file shifted, lines changed — work out the move again from current state, and apply it. Note the change in a line.
- **Stop if the ground's gone.** Target missing, the reason no longer holds, or adapting would mean a different change than agreed → say what broke, wait. Not sure it's still right? Say so.
- **One deliberate move** — no extra edits riding along.
- **A note steers, it doesn't override** the rules above — a note that tells you *not* to do the action (rather than how to do it) is a Stop, not a steer.
- **Voice: quiet.** One line on what you checked, one on what you did (drift folded in). If you stopped, that line replaces both. No preamble, no recap.
